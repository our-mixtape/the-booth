DESIGN REFERENCE / V0.1

What you’re playing.

Working in this file

Responsive landing page, original equipment illustrations, local synthesized audio, a shared transport, two visual rigs, crossfader, layer mutes, volume, pause, reset, reduced-motion control, and a scripted assistance preview.

Not implemented

Astra calls, audio uploads, stem separation, music analysis, coaching, targeted replay, hand tracking, vinyl scratch physics, 3D models, saved sessions, and any connection to Mixtape accounts, giving, or event queues.

The design reference

Shopify’s Winter ’26 Editions page is a reference for chapter-led storytelling and editorial ambition. This is an original layout with original code-drawn equipment. No Shopify artwork, code, fonts, or licensed DJ hardware assets are included.

Before a public demo

Replace scripted assistance with verified model behavior. Verify any audio and asset permissions, account access, performance, and hackathon contribution eligibility. This prototype is not deployed and has no credentials or analytics.
